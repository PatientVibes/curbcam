# Code of Conduct

## The short version

Be decent to people. Assume good faith. Critique code, not the person who wrote
it.

## Expected behaviour

- Be welcoming to newcomers. Not everyone has set up a Raspberry Pi before, and
  "how do I even start this" is a fair question.
- Give and take feedback gracefully. Reviews are about the change, not the
  author.
- Accept that people have different priorities, hardware, roads, and amounts of
  free time.

## Unacceptable behaviour

- Harassment, personal attacks, or demeaning comments.
- Sexualised language or imagery, or unwelcome attention of any kind.
- Publishing someone's private information without permission.
- Sustained disruption of discussions.

## A note specific to this project

curbcam records vehicles on public streets, which touches surveillance, privacy,
and local law. Reasonable people disagree about where the lines are, and those
discussions are welcome here.

What is **not** welcome is using this project — or its issue tracker — to
coordinate surveillance of specific individuals, or to help someone deploy it in
a way that is clearly unlawful where they live. If a request reads like
"help me track one particular person," the answer is no.

See the "Before you install" section of the README for the broader responsible-use
guidance.

## Scope

This applies in project spaces — issues, pull requests, discussions — and when
representing the project publicly.

## Enforcement

Report problems to the maintainer at the address in the commit history, or via a
[private security advisory](https://github.com/PatientVibes/curbcam/security/advisories/new)
if it is sensitive.

Reports will be reviewed and handled as the maintainer judges appropriate, which
may include a warning, removal of comments, or a ban from project spaces.
Whoever reports something in good faith will not be penalised for it.
